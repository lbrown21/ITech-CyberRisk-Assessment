# ITech-CyberRisk-Assessment
Fictional GRC Project using NIST 800-53 for a SaaS company


This project is a fictional GRC scenario for a mid-sized SaaS company using CRM software. It demonstrates my ability to apply risk management frameworks (NIST 800-53) in practical compliance situations (SOX, HIPAA).

## 📊 Project Summary

- **Industry:** SaaS (CRM)
- **Employees:** 300
- **Data Types:** PII, financial data, support tickets
- **Compliance Needs:** HIPAA, SOX, General Data Protection

## ✅ Key Sections
- Risk Register with Business Impact
- NIST 800-53 Control Mapping
- Remediation Plan with KPIs
- PDF and DOCX versions of the report included

## 📁 Files
- `ITech_Cyber_Risk_Findings.pdf` – Final report
- `risk_register.csv` – Risk analysis
- `control_mapping.csv` – Security control alignment
- `remediation_plan.csv` – Action plan with owners & timelines

## 🛠️ Skills Demonstrated
- Cyber Risk Assessment
- GRC Frameworks (NIST 800-53)
- Security Controls Mapping
- Remediation Planning
- Audit Readiness & Documentation
